# Lumina Photomosaic Engine

A high-performance, browser-based photomosaic generation suite. 

## Features
- **Sovereign Engine**: All processing happens locally on your device.
- **Mobile First**: Optimized for Android/iOS as a PWA.
- **High Fidelity**: Supports 4K and 8K master (web version) exports.
- **Perceptual Matching**: Uses CIELAB color space for superior accuracy.

## Mobile Installation (PWA)
To use this as an app on your Android device:
1. Open the GitHub Pages URL in **Chrome**.
2. Tap the menu (three dots) and select **"Add to Home Screen"** or **"Install App"**.
3. Lumina will now appear in your app drawer as a standalone utility.

## Development
```bash
npm install
npm run dev
```
